Process

Model comparison

1. Planning model

FILL IN — Which model produced docs/PLAN.md?

2. Critique and iteration

FILL IN — Which model critiqued the plan? Summarize the accepted and rejected critique points and why, using the project's decision log.

3. Implementation B

This implementation was produced independently from the written plan and targeted defect reports. It intentionally did not inspect implementation A.

FILL IN — Identify the implementation-B model, model version, and the exact prompt used to delegate the work.

4. Physics comparison

The primary comparison dimensions should be numerical agreement, treatment of the A = 1 limit, fractional-stage handling, clamp behavior, and how the shared physics API was separated from the UI.

FILL IN — Record measured differences between Implementation A and B without turning the comparison into an overall winner or score.

5. Interaction and accessibility comparison

Compare the direct-manipulation design, pointer handling, keyboard operation, mobile behavior, SVG geometry, and accessibility labeling.

FILL IN — Record observed differences from the browser-driving round.

6. Lessons from independent implementations

FILL IN — Explain what the comparison revealed about model independence, specification quality, verification, and the role of human review.
