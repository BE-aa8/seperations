How the explorer works

Overview

This tool compares an equilibrium-stage tray absorber with a continuous packed absorber doing the same dilute gas absorption duty. Two graphical endpoints choose gas outlet purity and liquid rate; the mass balance derives L/V.

Framing: this is an AI project exploring AI capabilities

The physics is separated from rendering and interaction so two independent implementations can be compared.
