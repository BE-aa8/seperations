Technical sources

The physics implemented here is standard dilute-absorption theory. The primary reference for this course, and the one every default value in the demo is to be checked against:

  • Seader, Henley & Roper, Separation Process Principles — Chapter 6, absorption and stripping of dilute mixtures. Source for the Kremser and Colburn treatments, the absorption factor, and the stage-versus-transfer-unit relationship.

Named equations

  • Kremser equation — the closed-form stage count for counter-current cascades with straight operating and equilibrium lines.
  • Colburn equation — the corresponding closed form for the number of overall gas-phase transfer units.
  • Souders–Brown and the generalised pressure-drop correlation — not implemented here; they are what a future column-diameter phase would be built on.

Software and standards

The site has no runtime dependencies and no build step. It is plain HTML, CSS and JavaScript modules, using only platform features:

  • SVG for every diagram and column drawing.
  • Pointer Events for dragging, so that one code path serves mouse, touch and pen.
  • Node's built-in test runner for the physics test suite — no test framework installed.
  • Netlify for static hosting.

The categorical colours used for the two column types were checked against colour-vision-deficiency separation and contrast thresholds in both light and dark themes rather than chosen by eye.
