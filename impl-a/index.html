Transfer units

Check: N × HETP = Z

This always passes, by construction: HETP is defined as HOGNOG/N, so the product is Z. It would catch an inverted g(A), but it is not independent validation. The checks that are independent — the stepped staircase against Kremser, and numerical integration against Colburn — run in the test suite.

What to try

  1. Starve the column of liquid

    Drag the bottom end of the operating line to the right until the minimum-L/V flag appears. The stage count runs away. A drops below 1 on the way; that is normal, not an error.

  2. Balance the lines

    At A = 1 the transfer-unit area becomes a rectangle, the packed profile a straight line, and N = NOG = 4 exactly. The near-balanced case should read the same.

  3. Change only the packing

    Switch from Pall rings to structured packing. NOG does not move; only the height does. That is how much separation is needed against how well the hardware delivers it.

  4. Break the model on purpose

    Sulphur dioxide is in the list because the straight-line model strains there. Read the caution it raises, and look at the liquid rate it demands.
