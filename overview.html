Tray vs. Packed Separation Processes · University of Cincinnati

One duty, two columns

An interactive comparison of a tray column and a packed column doing the same dilute gas absorption job. Built for Separation Processes at the University of Cincinnati as an AI project: the same specification was implemented independently by two different AI models, and both must pass the same physics test suite.

  • Implementation A The site. Chosen as the version to carry forward, on interface preference; the physics is identical in both. This is what the root URL opens.
  • Both, side by side Both implementations running next to each other, with blind mode and a side-swap so position does not steer the judgement. This is an interface comparison.
  • Implementation B ChatGPT's independent build from the same plan. Kept in full, exactly as delivered, as the evidence for the model comparison, not as a fallback.

Both are written against the same frozen module interface and graded by the same test suite, currently 65 / 65 each, and their physics agrees to the last digit across 4,837 operating points. The specification they were built from is docs/PLAN.md; the running decision log is docs/DECISIONS.md.
